# Contributing to Remote Sensing Portal

We welcome contributions! Please follow these guidelines:

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/remote-sensing-portal.git`
3. Create a feature branch: `git checkout -b feature/your-feature`
4. Make your changes
5. Commit: `git commit -am 'Add new feature'`
6. Push: `git push origin feature/your-feature`
7. Submit a Pull Request

## Code Style

### Python

- Follow PEP 8
- Use type hints
- Run `black` and `flake8` before committing

### JavaScript/React

- Follow Airbnb JavaScript style guide
- Use ESLint and Prettier
- Format with Prettier before committing

## Testing

- Write tests for new features
- Ensure all tests pass before submitting PR
- Maintain >80% code coverage

## Commit Messages

Use clear, descriptive commit messages:

```
type(scope): subject

details...

- type: feat, fix, docs, style, refactor, test, chore
- scope: feature or area affected
- subject: brief description (imperative)
```

## Pull Request Process

1. Update README.md if needed
2. Add tests for new features
3. Ensure CI/CD passes
4. Request review from maintainers
5. Address feedback

## Questions?

Open an issue or discussion for questions.

Thank you for contributing!
